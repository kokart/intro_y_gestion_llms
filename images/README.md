```markdown
Instrucciones para imágenes y logo
----------------------------------

- Coloque aquí los ficheros de imagen utilizados por la página:

  1. images/aepd-logo.png
     - Debe ser el logo oficial de la Agencia Española de Protección de Datos.
     - Asegúrese de tener permiso para usar el logo en una página pública. Compruebe la política de uso de identidad visual de la AEPD o contacte con su departamento de comunicación si es necesario.
     - Tamaño recomendado: alrededor de 48x48 px (puede usar SVG si lo tiene).

  2. images/profile.jpg
     - Fotografía de perfil de Alfredo Soto (o una imagen de reemplazo).
     - Tamaño recomendado: cuadrado, mínimo 600x600 px para buena calidad en retina.

- Si no dispone de las imágenes, puede usar placeholders temporales:
  - https://via.placeholder.com/220 (para profile.jpg)
  - O utilizar un SVG del logo en lugar de PNG (mejor escalabilidad).

- Para desplegar en GitHub Pages:
  - Suba todo el contenido (index.html, css/, images/) al branch `gh-pages` o `main` y active GitHub Pages en la configuración del repo.
```
